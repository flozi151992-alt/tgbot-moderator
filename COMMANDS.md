# 🤖 Команды бота-модератора

Полный справочник по всем командам Telegram бота-модератора.

## 📋 Основные команды

### `/start`
**Описание:** Активация бота в чате  
**Доступ:** Все пользователи  
**Пример:** `/start`

**Что делает:**
- В личных сообщениях: показывает информацию о боте
- В группах: активирует бота и показывает правила чата
- Логирует действие в базу данных

---

### `/help`
**Описание:** Справка по всем командам  
**Доступ:** Все пользователи  
**Пример:** `/help`

**Что показывает:**
- Список всех доступных команд
- Команды для администраторов (если пользователь - админ)
- Краткое описание функций бота

---

### `/rules`
**Описание:** Показать правила чата  
**Доступ:** Все пользователи  
**Пример:** `/rules`

**Что показывает:**
- Список запрещенных действий
- Список разрешенных действий
- Систему предупреждений (1→2→3)
- Информацию об автоматической модерации

---

### `/stats`
**Описание:** Статистика модерации чата  
**Доступ:** Только администраторы  
**Пример:** `/stats`

**Что показывает:**
- Общее количество сообщений в чате
- Количество удаленных сообщений
- Процент удаленных сообщений
- Работает только в групповых чатах

---

## 👮 Команды для администраторов

### `/unban [user_id]`
**Описание:** Разбанить пользователя  
**Доступ:** Только администраторы с правами на бан  
**Пример:** `/unban 123456789`

**Что делает:**
- Проверяет статус пользователя в Telegram
- Для ограниченных пользователей: восстанавливает права
- Для исключенных пользователей: снимает бан
- Очищает предупреждения в системе бота
- Отправляет уведомление о разбане
- Логирует действие администратора

**Типы разбана:**
- `restricted` → восстановление прав без исключения
- `kicked` → снятие бана (нужно заново пригласить)
- Работает с банами через бота и ручными банами

---

### `/warnings [user_id]`
**Описание:** Показать предупреждения пользователя  
**Доступ:** Только администраторы  
**Пример:** `/warnings 123456789`

**Что показывает:**
- Количество предупреждений (X/3)
- Текущий статус (warning/ban_24h/ban_permanent)
- Причину последнего нарушения
- Время последнего предупреждения
- Время окончания бана (если применимо)

---

### `/status [user_id]`
**Описание:** Проверить полный статус пользователя  
**Доступ:** Только администраторы  
**Пример:** `/status 123456789`

**Что показывает:**
- Статус в Telegram (member/restricted/kicked/left)
- Время ограничения (если есть)
- Статус в системе предупреждений бота
- Количество предупреждений и причины
- Информацию о пользователе (имя, username)

**Возможные статусы Telegram:**
- `member` - обычный участник
- `restricted` - ограничен в правах
- `kicked` - исключен из чата
- `left` - покинул чат сам
- `administrator` - администратор
- `creator` - создатель чата

---

### `/search [partial_id]`
**Описание:** Найти пользователей по части ID  
**Доступ:** Только администраторы  
**Пример:** `/search 12345`

**Что делает:**
- Ищет всех пользователей с ID, содержащим указанную часть
- Показывает информацию о предупреждениях
- Полезно при опечатках в ID или поиске похожих пользователей

**Что показывает:**
- User ID найденных пользователей
- Количество предупреждений
- Статус (warning/ban_24h/ban_permanent)
- Активность предупреждения
- Причину последнего нарушения
- Время последнего действия

---

### `/admins`
**Описание:** Список администраторов чата  
**Доступ:** Все пользователи  
**Пример:** `/admins`

**Что показывает:**
- Всех администраторов чата
- Роль (Владелец/Администратор)
- Имя и фамилию
- Username (если есть)
- Telegram ID

---

## ⚠️ Система предупреждений

### Как работает

1. **1-е нарушение:**
   - Сообщение удаляется
   - Отправляется предупреждение
   - Запись в базу данных: `warning_count=1, action_type='warning'`

2. **2-е нарушение:**
   - Сообщение удаляется
   - Пользователь блокируется на 24 часа
   - Отправляется уведомление о блокировке
   - Запись в базу данных: `warning_count=2, action_type='ban_24h'`

3. **3-е нарушение:**
   - Сообщение удаляется
   - Пользователь блокируется навсегда
   - Отправляется уведомление о постоянном бане
   - Запись в базу данных: `warning_count=3, action_type='ban_permanent'`

### Автоматические действия

- **Удаление сообщений** - мгновенно
- **Предупреждения** - отправляются в чат
- **Блокировки** - через Telegram API
- **Логирование** - все действия записываются

### Разбан пользователей

Администраторы могут разбанить пользователя командой `/unban [user_id]`:
- Очищаются все предупреждения
- Восстанавливаются права в Telegram
- Пользователь может снова участвовать в чате

## 🔧 Технические детали

### Обработка команд

Команды обрабатываются в следующем порядке:
1. Основные команды (`/start`, `/help`, `/rules`, `/stats`)
2. Команды администратора (`/unban`, `/warnings`, `/status`, `/search`, `/admins`)
3. Общий обработчик сообщений (модерация)

### Проверка прав

- **AdminUtils.is_admin()** - проверка прав администратора
- **AdminUtils.can_ban_users()** - проверка прав на бан
- **AdminUtils.is_owner()** - проверка владельца чата

### Обработка ошибок

- Все команды имеют обработку ошибок
- Логирование ошибок в файл и базу данных
- Пользователю отправляются понятные сообщения об ошибках

## 📊 Примеры использования

### Сценарий 1: Модерация нарушителя
```

↓
Бот удаляет сообщение
↓

↓

↓

Администратор: /status 123456789
↓
Бот показывает статус пользователя
↓
Администратор: /unban 123456789
↓
Бот разбанивает пользователя
↓
Отправляется уведомление о разбане
```

```
Администратор: /search 12345
↓
Бот ищет пользователей с похожим ID
↓
Показывает список найденных пользователей
↓
Администратор может проверить статус или разбанить
```

## 🚨 Важные замечания

1. **Права бота:** Бот должен быть администратором с правами на удаление сообщений
2. **Владельцы чатов:** Нельзя забанить владельца чата (ошибка "can't remove chat owner")
3. **ID пользователей:** Используйте точные Telegram ID пользователей
4. **Timezone:** Все времена в UTC, отображаются в локальном времени
5. **Персистентность:** Данные сохраняются между перезапусками контейнера
