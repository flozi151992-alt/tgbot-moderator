# 📋 Changelog - История изменений

## 🚀 Версия 2.0.0 (Сентябрь 2025)

### ✨ Новые возможности

#### 🔧 Обновления библиотек
- **aiogram**: обновлен с 3.12.0 до 3.21.0
- **SQLAlchemy**: переход на полноценный ORM вместо raw SQL
- **asyncpg**: обновлен до версии 0.29.0
- **python-dotenv**: обновлен до версии 1.0.1

#### ⚠️ Система предупреждений
- **Восстановлена** система прогрессивных наказаний
- **1-е нарушение**: Предупреждение
- **2-е нарушение**: Блокировка на 24 часа
- **3-е нарушение**: Постоянная блокировка
- **Таблица user_warnings**: Полная интеграция с существующей схемой БД

#### 👮 Команды администратора
- **`/unban [user_id]`** - Разбан пользователей (работает с любыми банами)
- **`/warnings [user_id]`** - Просмотр предупреждений пользователя
- **`/status [user_id]`** - Детальный статус пользователя в чате
- **`/search [partial_id]`** - Поиск пользователей по части ID
- **`/admins`** - Список администраторов чата

#### 🏗️ Архитектурные улучшения
- **WarningRepository** - репозиторий для управления предупреждениями
- **BanManager** - менеджер для обработки банов и ограничений
- **AdminUtils** - утилиты для проверки прав администратора
- **LoggingMiddleware** - централизованное логирование сообщений
- **Error Handler** - обработчик ошибок с записью в БД

#### 🔍 Улучшения фильтра
- **Добавлены новые слова**: "мразота" и другие
- **Транслитерация**: распознавание "ye xnj tot" и подобных
- **Расширенные паттерны**: улучшенное распознавание замаскированных слов

### 🐛 Исправленные ошибки

#### 🔧 Технические исправления
- **HTML-теги в командах**: заменены `<user_id>` на `[user_id]`
- **Datetime comparison**: исправлены ошибки сравнения timezone-aware/naive
- **SQLAlchemy cast**: исправлена ошибка с приведением типов
- **Порядок обработчиков**: команды админа перемещены перед общим обработчиком

#### 🚫 Исправления банов
- **Разбан ограниченных пользователей**: используется `restrict_chat_member` вместо `unban_chat_member`
- **Обработка владельцев чатов**: корректная обработка ошибки "can't remove chat owner"
- **Персистентность данных**: убрана команда `drop_all()` при инициализации БД

#### 📊 Исправления базы данных
- **ORM модели**: полный переход на SQLAlchemy ORM
- **Инициализация сессий**: исправлена проблема с глобальными переменными
- **Автоинициализация**: репозитории автоматически инициализируют БД при необходимости

### 🔄 Миграции

#### База данных
- Таблицы теперь создаются через ORM (`Base.metadata.create_all()`)
- Сохранена совместимость с существующей таблицей `user_warnings`
- Добавлены индексы для оптимизации запросов

#### Docker
- **Health check**: обновлен для работы с новой архитектурой
- **.dockerignore**: добавлен для оптимизации сборки
- **Middleware**: интегрирован в Docker-сборку

### 📈 Улучшения производительности

- **ORM запросы**: более эффективные запросы к базе данных
- **Connection pooling**: оптимизированное управление соединениями
- **Middleware**: централизованное логирование без дублирования
- **Error handling**: улучшенная обработка ошибок без падений

### 🛡️ Безопасность

- **Проверка прав**: все админ-команды проверяют права пользователя
- **Валидация входных данных**: проверка форматов user_id
- **Graceful error handling**: корректная обработка ошибок Telegram API
- **Логирование действий**: все админ-действия записываются в БД
